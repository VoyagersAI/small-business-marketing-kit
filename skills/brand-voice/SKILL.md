# Brand voice

Fill this in with the owner, one section at a time. Leave a blank as [NOT SURE YET] rather than guessing. Save it to the backup folder as "Voice Guide" and send it for a KEEP before using it.

## Template
* Business name, written exactly: [YOUR BUSINESS NAME]
* What we do in one sentence: [WHAT YOU DO]
* Who we serve: [YOUR IDEAL CUSTOMER]
* The one action we want: [VISIT, CALL, BOOK, BUY, OR OTHER]
* Three words for how we sound: [WORD 1], [WORD 2], [WORD 3]
* We sound like this (one sample sentence from the owner): [SAMPLE]
* We never sound like this: [SAMPLE TO AVOID]
* Words and phrases we like: [LIST]
* Words, emojis, or punctuation we never use: [LIST]
* Topics we post about: [TOPIC 1], [TOPIC 2], [TOPIC 3]
* Off limits topics and claims: [LIST]
* Hashtags we use: [LIST]
* Hashtags we never use: [LIST]
* Reading level and length: [SHORT AND SIMPLE, OR OTHER]

## Using it
* Read the guide before every draft.
* If a draft breaks a "never" rule, rewrite it before it reaches the owner.
* When the owner edits a draft, ask if the change should go into the guide.
* Never copy another business's voice or content.
