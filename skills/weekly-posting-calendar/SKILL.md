# Weekly posting calendar

## Set up
Ask the owner and save the answers:
* Platforms: [PLATFORM LIST]
* Posts per week per platform: [NUMBER]
* Days and times: [DAYS AND TIMES]
* Time zone: [TIME ZONE]
* Content mix: [EXAMPLE: TIPS, BEHIND THE SCENES, OFFERS, QUESTIONS]

## Calendar row
Each planned post gets one row: date, time, platform, topic, draft link, status.
Status is one of: Idea, Drafted, Waiting yes, Approved, Scheduled, Posted, Skipped.
The row tracks the plan. The lasting copy of the caption and the still is the post record below.

## Lasting post record
Chats reset. From now on, every draft that gets a KEEP, and every post that goes live, also gets one entry in a lasting post record in the backup folder.

Prefer one Google Doc. Use the doc the owner already set up in the backup folder. If there isn't one, create it there and name it Post Record.

Each entry scrolls as one unit. The still (the picture that goes with the post) and the caption sit in that same entry: still first, caption right under it.
* Keep the still with the caption in the same entry. A caption with no still beside it, or a still link kept in another file, is not the record.
* Until a connector can place the picture in the doc, a Drive link to the still on the line right above the caption is enough. Put the picture in the doc as soon as a connector can.
* After a KEEP, write the entry. When the post goes live, update that same entry with the date, the platform, and that it is live. If the caption or the still changes, update that same entry.
* Older entries can stay as they are. Do not rebuild them.

## Weekly rhythm
1. Plan next week's rows from the content mix.
2. Draft each post using the brand-voice skill.
3. Move drafts to Waiting yes using the keep-approval-gate skill.
4. Schedule only what has a KEEP, then open it and check before marking it Scheduled.
5. After a KEEP, and again when the post is live, save the still and the caption together in the lasting post record.

## Health check
Look two weeks ahead. If a planned day has no approved post, tell the owner once, in plain words, with what's missing. Stay quiet when nothing is missing.
