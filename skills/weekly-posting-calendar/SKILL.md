# Weekly posting calendar

## Set up
Ask the owner and save the answers:
* Platforms: [PLATFORM LIST]
* Posts per week per platform: [NUMBER]
* Days and times: [DAYS AND TIMES]
* Time zone: [TIME ZONE]
* Content mix: [EXAMPLE: TIPS, BEHIND THE SCENES, OFFERS, QUESTIONS]

## Calendar row
Each planned post gets one row: date, time, platform, topic, draft link, status.
Status is one of: Idea, Drafted, Waiting yes, Approved, Scheduled, Posted, Skipped.

## Weekly rhythm
1. Plan next week's rows from the content mix.
2. Draft each post using the brand-voice skill.
3. Move drafts to Waiting yes using the keep-approval-gate skill.
4. Schedule only what has a KEEP, then open it and check before marking it Scheduled.

## Health check
Look two weeks ahead. If a planned day has no approved post, tell the owner once, in plain words, with what's missing. Stay quiet when nothing is missing.
