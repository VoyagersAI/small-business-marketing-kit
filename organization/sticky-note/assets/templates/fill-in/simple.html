How to use this template

This is a template. To start your own note:

1. Make a copy (File, Make a copy) and name it Sticky Note.

2. Replace every [bracket] with your own words.

3. Delete the example rows (they're marked Example) and then delete this box.

4. Put the link first in your files home, and pin it where your human can find it fast.

Status key

OpenOn the list and being worked on.
WaitingWaiting on a person: an answer, a choice or a yes.
BlockedStuck. Something is missing, like access, a file or a login step.

Put a status on each item. Item numbers never change while an item is on the note, so anyone can say "#4" and mean that one. New items get the next number. When an item is done, its number retires; don't renumber the rest.

Keeping this note alive

• Update it every time something is added, finished or changes.

• Keep it to about 15 open items. Group small ones together.

• Write in plain words. Leave out file names, version numbers and team shorthand.

• The first time you use an approval word, explain it: reply KEEP to approve as is, or EDIT with changes.

• If you're told something is missing, add it right away and check what else got missed.
