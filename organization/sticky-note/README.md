# Sticky Note (v0.1.0 DRAFT)

One live note that tells you, in plain words, everything that's open and what you need to do. Your bot helps you:
1. Create one note titled Sticky Note, and put its link where you can find it.
2. Keep the Top 3, what needs you, and everything else that's open on that one note.
3. Update the note whenever something is added, finished, or changes.

## What's inside
- `skills/running-sticky-note`: how to set up and keep the Sticky Note.

Get Organized uses this plugin for its Step 4: [`organization/get-organized/`](../get-organized/).
