# Get Organized v1: how Tom tries it with Picard (today, Oct 19)

**What this is:** a first test of the Get Organized plugin. Picard runs the four steps on a small part of Tom's files and puts loose to-dos on one Sticky Note (creates it if Tom doesn't have one). It's a test, so we keep it small and safe.

## Before you start (2 minutes)
- Pick ONE small area to test on: one Drive folder or one project, not everything.
- Tom may not have a Sticky Note yet — Picard should create one in Step 4.
- Give Picard the Get Organized skill: paste the text of `get-organized` SKILL, or load the plugin folder if Picard can. Step 4 uses the Sticky Note plugin ([`organization/sticky-note/`](../sticky-note/)). If it isn't installed, ask Tom to install it before Step 4.

## Steps (about 30 to 45 minutes)
1. Tell Picard: **"Use the Get organized skill on [folder/project]. Look and list only. Change nothing until I say KEEP."**
2. **Step 1, one home:** Picard asks where files live and suggests one home and a few folder names. Tom answers KEEP / EDIT.
3. **Step 2, one live copy:** Picard lists duplicates as numbered lines. Tom answers in one line, like "1 KEEP, 2 HOLD". Only KEEP'd items move, and only to Archive or the trash.
4. **Step 3, Start Here:** Picard drafts the Start Here page with the Sticky Note link first. Tom reads it and says KEEP or EDIT.
5. **Step 4, Sticky Note:** If Tom has no Sticky Note, Picard creates one. Then it moves loose to-dos onto that one note (never a second), each with where it was found.
6. Picard gives the finish report: home link, duplicates found and waiting, to-dos moved, anything on "Needs sign-in".

## What done looks like
- Tom opens ONE link (the Start Here page) and in under a minute knows where things are and what's open.
- One live copy of each tested file; old copies in Archive or trash, nothing deleted for good.
- Every loose to-do from the test area is on the Sticky Note, and there's still only one Sticky Note.
- Nothing moved without Tom's yes.
